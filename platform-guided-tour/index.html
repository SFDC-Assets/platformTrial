Tour the App

Explore the components and data in Connected Executive Education's custom application

The Learning Management App is a fully configured, custom application that CEE built on the Agentforce 360 Platform. Before you start working with AI agents or metadata tools, take a brief tour of the core building blocks of this app.

Courses

The Courses object stores all offerings available in CEE's executive education catalog. Each record includes essential details such as category, delivery format, duration, and instructor information.

Students

The Students object captures learner profiles for individuals enrolled in CEE's executive programs. Each profile includes the learner's name, role, organization, and contact information.

Enrollments

The Enrollments object connects students to their courses and tracks their progress. Each enrollment record includes the course name, student assigned, start dates, and progress indicator.
