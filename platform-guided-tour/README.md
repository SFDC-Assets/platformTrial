# Salesforce Platform Guided Tour

An interactive guided tour showcasing the Agentforce 360 Platform capabilities based on the Free Trial Guide content.

## Overview

This guided tour provides a step-by-step walkthrough of the Salesforce Platform features, including:

1. **Tour the App** - Explore the Connected Executive Education application
2. **Agentforce Builder** - Build and customize agents with no code
3. **Test Agentforce** - Validate agents with automated testing
4. **Agentforce Vibes** - Developer productivity with vibe coding
5. **Deploy Securely** - Deploy with built-in metadata tools
6. **Event Monitoring** - Track and analyze org changes

## Setup

1. Open `index.html` in a web browser
2. Navigate through steps using:
   - Sidebar navigation
   - Previous/Next buttons
   - Keyboard arrows (← →)

## Adding Screenshots

Place screenshot images in the `images/` directory and update the image paths in `index.html`:

- Update content in `index.html` sections
- Modify styles in `css/styles.css`
