## Extraction Instructions

To extract images from static resources:

1. Static resources are binary files in `force-app/main/default/staticresources/`
2. You can:
   - Deploy to an org and download from Static Resources
   - Use a tool to extract the binary content
   - Copy the original image files if available

3. Rename extracted images to match the names above
4. Place all images in the `platform-guided-tour/images/` directory
